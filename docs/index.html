    The split is the compliance story

    The LLM decides what to investigate and what matters. It never produces a number. Every claim dereferences to a recorded run. A hallucinated statistic is structurally impossible, not merely discouraged.

    1. Elicit feature mutability → human gate
    2. Run the mandatory battery
    3. Form hypotheses from surprises
    4. Design and run follow-up experiments
    5. Judge materiality
    6. Synthesise the memo from the investigation graph

    Figure discipline

    The turn worth rehearsing

    The battery says the model is gameable. The follow-up says gamed approvals are worse. The integrity gap says the honest path is two orders of magnitude more expensive. Then the recorded/true DTI split appears — and Route C is free. The people the model excludes could be approved for nothing. That is the case file.

    Boundaries

    • Janus does not make credit decisions.
    • Attack recipes stay with the model owner. Aggregate only elsewhere. Never to applicants.
    • Recourse routes travel through the lender’s adverse-action process.
    • Findings are diagnostic. Remediation stays with the lender.
